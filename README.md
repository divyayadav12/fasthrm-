# WorkPulse - Staff Work Tracking & Live Project Management System

WorkPulse is a complete production-ready full-stack web application designed for real-time employee monitoring and project management. 

## Features
- **Admin Dashboard**: Real-time team status updates via Socket.io without page refreshes.
- **Employee Work History**: A permanent, unalterable log of all employee activities and status changes. Filterable by date, project, and task.
- **Project & Task Management**: Full CRUD operations for Projects and Tasks. Assign tasks, track progress, and monitor bottlenecks.
- **Reporting & Analytics**: Comprehensive visual reports on employee productivity, task statuses, and project completion rates using Recharts.
- **Notifications**: Real-time assignment and status update notifications.
- **Role-Based Access Control**: Secure JWT-based authentication for Admins and Employees.

## Tech Stack
**Frontend:** React.js, TypeScript, Vite, Tailwind CSS, Redux Toolkit, React Router, Socket.io-client, Recharts, Lucide React  
**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT authentication, bcrypt, Socket.io  
**Architecture:** Monorepo with separated `frontend/` and `backend/` directories.

## Installation & Setup

1. **Clone the repository and install dependencies:**
   ```bash
   cd backend
   npm install
   cd ../frontend
   npm install
   ```

2. **Environment Variables:**
   - Copy `backend/.env.example` to `backend/.env` and update `JWT_SECRET` and `MONGODB_URI`.
   - Copy `frontend/.env.example` to `frontend/.env`.

3. **Start MongoDB (if using Docker):**
   ```bash
   docker-compose up -d
   ```

4. **Seed Database:**
   ```bash
   cd backend
   npm run seed
   ```

5. **Run the Application:**
   ```bash
   # Terminal 1: Backend
   cd backend
   npm run dev

   # Terminal 2: Frontend
   cd frontend
   npm run dev
   ```

## Production Deployment
1. Build the frontend: `cd frontend && npm run build`
2. Build the backend: `cd backend && npm run build`
3. Host the frontend static files (from `frontend/dist`) on a CDN or Nginx server.
4. Host the backend Node.js server using PM2 or Docker. Ensure WebSocket upgrade headers are passed correctly in your reverse proxy for Socket.io to function.
